6 · Hitungan biaya kasar

Asumsi: 1.000 chunk × 400 token; tiap pertanyaan mengirim 6 chunk (2.400 token) + 300 token instruksi, output 300 token.

TahapPerhitunganBiaya
Embedding seluruh korpus400 rb token × $0,012/M≈ $0,005 (sekali)
Query + jawaban (qwen3-30b)2,7 rb × $0,051/M + 300 × $0,335/M≈ $0,00024 / pertanyaan
Query + jawaban (llama-3.3-70b)2,7 rb × $0,293/M + 300 × $2,253/M≈ $0,0015 / pertanyaan
Rerank 20 kandidat8 rb token × $0,003/M≈ $0,00002 / pertanyaan

Konsekuensi praktis: 10.000 neuron/hari ≈ 400 pertanyaan/hari dengan model 30B murah. Embedding korpus pribadi praktis gratis; biaya sebenarnya ada di token jawaban.

7 · Checklist produksi

  • ID vektor deterministik (source#index) supaya ingestion idempotent.
  • Rekonsiliasi chunk lama: hapus di D1 dulu, lalu deleteByIds di Vectorize.
  • Ingestion di Workflow/Queue, bukan di request handler.
  • Metadata index dibuat sebelum vektor pertama di-upsert.
  • Beri waktu propagasi (±1 menit) sebelum menyimpulkan upsert/hapus gagal.
  • Prompt mewajibkan sitasi dan menolak menjawab tanpa konteks.
  • Chunk diperlakukan sebagai input tidak tepercaya (risiko prompt injection dari dokumen).
  • Rate limit + cache di AI Gateway; log pertanyaan yang gagal.
  • Set evaluasi (10–30 pertanyaan) dijalankan setiap kali chunking/prompt berubah.
