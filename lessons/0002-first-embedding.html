Panggilan pertama: dari nol ke vektor

Sepuluh menit lagi kamu punya Worker ter-deploy yang mengubah teks menjadi 1.024 angka. Ini satu-satunya bagian RAG yang benar-benar "AI" di sisi ingestion — sisanya rekayasa data.

1 · Scaffold

Buat project TypeScript kosong. Pilih Hello World → Worker only → TypeScript, git ya, deploy tidak.

npm create cloudflare@latest -- rag-belajar
cd rag-belajar

Yang penting cuma dua file: wrangler.jsonc (konfigurasi + binding) dan src/index.ts (kode). Tidak ada server, tidak ada Docker, tidak ada region.

rag-belajar/
├── src/
│   ├── index.ts      # route Hono + export ulang IngestWorkflow
│   ├── ingest.ts     # extract(), chunkText(), IngestWorkflow
│   ├── search.ts     # embedding query, join D1, rerank, RRF
│   ├── chat.ts       # prompt, generation, verifikasi sitasi
│   └── prompt.ts     # konstanta SYSTEM
├── scripts/
│   └── eval.mjs      # harness evaluasi
├── schema.sql
└── wrangler.jsonc

Sesi ini hanya menyentuh src/index.ts dan wrangler.jsonc. File lain muncul di sesi berikutnya — setiap blok kode di seri ini diberi label nama file tujuannya, jadi kamu tidak perlu menebak.

2 · Binding, bukan API key

Di Cloudflare, akses ke layanan lain diberikan lewat binding: deklarasi di konfigurasi yang muncul sebagai objek di env. Tidak ada kredensial yang bisa bocor di kode atau di .env.

{
  "$schema": "./node_modules/wrangler/config-schema.json",
  "name": "rag-belajar",
  "main": "src/index.ts",
  "compatibility_date": "2026-11-01",
  "ai": {
    "binding": "AI",
    "remote": true
  }
}

"remote": true membuat wrangler dev memanggil model sungguhan saat development, bukan meniru hasilnya. Inferensi tetap berjalan di jaringan Cloudflare, jadi model yang kamu uji sama dengan yang nanti dipakai di produksi.

Setelah mengubah konfigurasi, jalankan ini sekali:

npx wrangler types

Perintah itu menghasilkan tipe untuk env dari binding yang kamu deklarasikan. Kalau nanti env.AI dianggap tidak ada oleh TypeScript, hampir selalu jawabannya: wrangler types belum dijalankan.

3 · Panggilan pertama

Ganti isi src/index.ts:

export default {
	async fetch(request, env): Promise<Response> {
		const { data, shape } = await env.AI.run("@cf/baai/bge-m3", {
			text: ["Halo, ini uji coba embedding."],
		});

		return Response.json({
			shape,
			dimensions: data[0].length,
			firstFive: data[0].slice(0, 5),
		});
	},
} satisfies ExportedHandler<Env>;

Jalankan npx wrangler dev, buka http://localhost:8787. Yang keluar kira-kira:

{
  "shape": [1, 1024],
  "dimensions": 1024,
  "firstFive": [-0.0123, 0.0441, -0.0087, 0.0204, 0.0311]
}

Itu dia inti RAG. Satu kalimat menjadi satu titik di ruang 1.024 dimensi. Tidak ada yang bisa dibaca manusia di angka-angka itu — maknanya hanya ada dalam jarak antar vektor.

Bentuk respons

shape adalah [jumlah input, dimensi]. data adalah array vektor, satu per input, dalam urutan yang sama. Model ini menerima satu string atau array string.

4 · Kenapa bge-m3

Tutorial resmi Cloudflare memakai bge-base-en-v1.5. Kita tidak, karena dokumenmu berbahasa Indonesia.

ModelDimensiBahasaHarga input
@cf/baai/bge-small-en-v1.5384Inggris$0,020 / juta token
@cf/baai/bge-base-en-v1.5768Inggris$0,067 / juta token
@cf/baai/bge-m31024Multibahasa$0,012 / juta token
@cf/qwen/qwen3-embedding-0.6b1024Multibahasa$0,012 / juta token

Perhatikan dua hal. Pertama, model multibahasa justru lebih murah daripada model Inggris kecil sekalipun. Kedua, dimensi berbeda-beda — dan ini keputusan yang tidak bisa diubah setelah indeks dibuat.

Kandidat yang seri

@cf/qwen/qwen3-embedding-0.6b punya dimensi dan harga yang sama, konteks lebih pendek (8k), dan pada benchmark retrieval multilingual justru tampil lebih tinggi. Kita memakai bge-m3 karena API-nya satu bentuk dan tidak butuh instruksi query — lebih sedikit cara untuk salah. Ini baseline yang aman, bukan pemenang yang terbukti. Di sesi 6 kamu akan punya alat untuk mengujinya sendiri.

Keputusan yang mengikat

Indeks Vectorize dikunci pada satu dimensi. Kalau nanti kamu pindah model, kamu membuat indeks baru dan mengisi ulang seluruh vektor. Pilih sekarang dengan sadar; ganti model = migrasi, bukan setting.

6 · Biaya dan batas

Workers AI memberi 10.000 neuron gratis per hari. Embedding bge-m3 memakan sekitar 1.075 neuron per juta token — artinya 10.000 neuron cukup untuk sekitar 9 juta token, atau kira-kira 20.000 halaman teks, per hari, gratis. Embedding bukan bagian yang mahal dalam RAG.

Yang mahal nanti adalah token output model generasi. Ingat angka itu untuk sesi 6.

7 · Latihan: buktikan embedding menangkap makna

Ganti handler dengan yang membandingkan tiga kalimat. Ini latihan 30 detik yang membuat konsep "jarak" jadi konkret.

function cosine(a: number[], b: number[]) {
	let dot = 0, na = 0, nb = 0;
	for (let i = 0; i < a.length; i++) {
		dot += a[i] * b[i];
		na += a[i] * a[i];
		nb += b[i] * b[i];
	}
	return dot / (Math.sqrt(na) * Math.sqrt(nb));
}

export default {
	async fetch(request, env): Promise<Response> {
		const { data } = await env.AI.run("@cf/baai/bge-m3", {
			text: [
				"cara menyeduh kopi",
				"resep espresso di rumah",
				"pajak kendaraan bermotor",
			],
		});

		return Response.json({
			kopi_vs_espresso: cosine(data[0], data[1]),
			kopi_vs_pajak: cosine(data[0], data[2]),
		});
	},
} satisfies ExportedHandler<Env>;

Kalimat pertama dan kedua tidak berbagi satu kata pun, tapi skornya akan jauh lebih tinggi daripada ke kalimat pajak. Itulah yang dimaksud "mirip secara makna" — dan itu sebabnya pencarian vektor bisa menemukan dokumen yang tidak memakai kata yang sama dengan pertanyaanmu.

Hasil sesi ini

Worker ter-deploy, binding AI bekerja, dan kamu sudah melihat sendiri bahwa embedding mengukur kemiripan makna, bukan kemiripan kata.

8 · Cek pemahaman

Dari memori: apa yang terjadi kalau dokumen di-embed dengan bge-m3 tapi pertanyaan di-embed dengan bge-base-en-v1.5?

Vektornya berada di ruang yang berbeda dan dimensinya pun berbeda (1024 vs 768). Query akan gagal karena dimensi tidak cocok, atau — kalau kebetulan dimensinya sama — skornya tidak bermakna. Aturannya mutlak: model yang sama untuk indexing dan query.
